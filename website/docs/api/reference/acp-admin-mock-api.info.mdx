OpenAPI for the ACP Admin mock API (`worker/` + optional `mock/server.mjs`).

**Base URLs:**
- Production / Worker preview: same-origin `/api`
- Local standalone mock: `http://localhost:4001` (`make mock`)

Use **Try It** in the docs (or the curl examples below).
