OpenAPI da API mock do ACP Admin (`worker/` + `mock/server.mjs` opcional).

**URLs base:**
- Produção / preview no Worker: `/api` na mesma origem
- Mock local standalone: `http://localhost:4001` (`make mock`)

Use **Try It** nestes docs (ou os exemplos curl em [Exemplos REST](../rest-examples)).

### Credenciais demo

Tokens de auth são retornados para a UI admin, mas **não são exigidos** pelo mock
nas rotas de coleção (CRUD do json-server é aberto).
